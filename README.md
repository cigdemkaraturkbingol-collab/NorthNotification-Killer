# NorthNotification-Killer

Android 13+ bildirim kontrol uygulaması.

- Kotlin + HTML arayüz
- Shizuku UserService
- Uygulama bazlı bildirim aç/kapat
- Toplu bildirim aç/kapat
- GitHub Actions ile otomatik debug APK derleme

APK, başarılı Actions çalışmasında `NorthNotification-Killer-APK` artifact'i olarak yüklenir.
